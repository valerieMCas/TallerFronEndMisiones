      Reglas de RutaMMAV

      1. Requisitos: un módulo solo entra a tu ruta si sus requisitos ya están antes que él.
      2. Máximo 7 módulos en la ruta, para no saturarte.
      3. No dejar huecos: no puedes quitar un módulo si otro de tu ruta lo necesita.
      4. Un solo foco: solo puedes tener un módulo «en curso» a la vez.
      5. Desbloqueo: para empezar un módulo, sus requisitos deben estar completados.
      6. Siguiente recomendado: la app resalta el próximo módulo de tu ruta que ya puedes empezar.
      7. Insignias: ganas medallas al completar ciertos módulos (por ejemplo, «Front básico» al terminar HTML5 y CSS).
      8. Biblioteca más cercana: con tu ubicación te recomendamos dónde estudiar, según el tipo de biblioteca que prefieras.
      9. Modo estudio: si estás en una biblioteca (a menos de 150 m), la app lo reconoce y te sugiere qué estudiar.

      Prototipo hecho solo con HTML, CSS y JavaScript. Tus datos se guardan en este navegador.
